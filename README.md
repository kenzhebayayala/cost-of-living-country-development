# cost-of-living-country-development
Data Engineering project analyzing the relationship between cost of living and country development indicators.


## Project Overview

This project analyzes the relationship between the cost of living and country development indicators.

We use Cost of Living data from Numbeo and country development data from the World Bank. The datasets are cleaned, combined, and analyzed to identify relationships between economic development and living costs across countries.

## Data Sources

- Numbeo – Cost of Living Index by Country
- World Bank API – country development indicators

## Indicators

The project includes indicators such as:

- Cost of Living Index
- Rent Index
- Groceries Index
- Restaurant Price Index
- Local Purchasing Power
- GDP per capita
- Life expectancy
- Unemployment

## Project Steps

1. Scrape Cost of Living data from Numbeo.
2. Clean and prepare the Numbeo dataset.
3. Collect development indicators using the World Bank API.
4. Clean and merge the datasets by country.
5. Perform descriptive and correlation analysis.
6. Create data visualizations.
7. Summarize the main findings.
